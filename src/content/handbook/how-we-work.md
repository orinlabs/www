## Communication

We prefer writing over meetings. If a meeting seems pointless or could be handled in writing, call it out.

Using AI for writing is banned. You may use AI to research or prep your writing, but if you recieve an AI-written communication from another employee, you should ask them to write it themselves. This includes emails, Slack, PR comments, etc. If the writing is supposed to be read by someone, write it yourself.

Code is intended to be run, not read, so we encourage you to use AI to generate code. See [Engineering](/handbook/engineering).
